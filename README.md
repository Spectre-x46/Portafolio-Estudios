# 🚀 Mi Portfolio Personal - Proceso de Aprendizaje

¡Hola! Soy **Felipe**, estudiante de **Desarrollador Full Stack y Ciberseguridad**. Este repositorio es mi proyecto principal del segundo módulo del bootcamp de Desarrollador Full Stack en Python, donde estoy aprendiendo las bases del desarrollo **Front-End**.

El objetivo de este sitio es aplicar paso a paso lo aprendido en cada clase, desde la estructura básica hasta hacerlo totalmente interactivo.

## 🛠️ Lo que he aplicado hasta ahora
He seguido el plan de estudios del curso y esto es lo que ya está funcionando:

* **HTML5 Semántico**: Aprendí sobre el esqueleto y a usar etiquetas como `header`, `nav`, `section` y `footer` para que la página esté bien organizada.
* **CSS con Variables**: Definí una paleta de colores estilo **"Tron"** usando `:root` para que sea fácil de mantener y cambiar.
* **Modelo de Caja (Box Model)**: Creé tarjetas para mis proyectos usando `padding`, `border` y `margin` para darles un aspecto moderno y con efectos de sombra al pasar el mouse.
* **Diseño Responsivo**: El sitio ya se adapta a celulares y tablets usando **Media Queries**. Me aseguré de que el menú de navegación sea cómodo de usar en pantallas pequeñas..
* **Formulario de Contacto**: Implementé un formulario con validación básica para recibir mensajes.
